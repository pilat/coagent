# Support

Use a GitHub issue for reproducible bugs and feature requests. Search existing
issues first and include the coagent version, operating system, relevant
configuration with secrets removed, and the smallest useful reproduction.

This community project does not promise response times or private operational
support. Questions that do not describe a product defect may be closed or
redirected. Suspected vulnerabilities belong in the private channel described
in `SECURITY.md`, never in a public issue.
